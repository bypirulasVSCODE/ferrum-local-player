# Contribuir a FERRUM

FERRUM está en beta y las contribuciones son bienvenidas.

## Reportar un problema

Abre un issue con pasos para reproducirlo, resultado esperado, resultado actual y versión de Windows. No adjuntes archivos de audio privados, credenciales ni datos personales.

## Proponer cambios

1. Haz un fork y crea una rama descriptiva.
2. Mantén los cambios pequeños y enfocados.
3. Comprueba la sintaxis JavaScript (`node --check`) y compila el ejecutable en Windows.
4. Envía un pull request con resumen, motivo y pasos de verificación.

## Alcance

FERRUM es un reproductor local. No agregues descargas de audio, extracción de streams, credenciales o servicios que suban la biblioteca del usuario. No incluyas música con copyright ni secretos en los commits.

Al enviar una contribución, aceptas que se distribuya bajo la licencia MIT del proyecto.
